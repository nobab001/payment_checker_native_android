# Brand Guideline

## Brand names

- **Product:** Payment Checker
- **Short / app:** PayChek
- **Domain:** paycheckbd.com

## Voice

- Confident, clear, operator-friendly
- Bangla UI copy is first-class for merchant/device operators
- English for product title and technical tags (e.g. Secure • Fast • Reliable)

## Visual personality

Inspired by premium SaaS (Stripe, Linear, Vercel): generous breathing room, indigo/blue trust palette, crisp typography, restrained motion.

## Logo usage

- Current app mark: Material wallet icon inside rounded square with brand gradient (Compose). Do not replace with unrelated iconography without a brand update.
- Clear space: ≥ 8dp around the mark on auth screens.
- Soft shadow/glow allowed; avoid harsh neon outlines.

## Tagline

`Secure • Fast • Reliable` — use as a pill or secondary accent line, never louder than the product name.

## Do

- Keep social brand colors accurate (WhatsApp green, Facebook blue, Telegram cyan, YouTube red).
- Use operator colors only on gateway tiles/methods.

## Don’t

- Mix more than one primary CTA color on the same screen.
- Stretch the logo.
- Place low-contrast grey text on grey surfaces.
